# Dry Run Notes — release hygiene checklist

This file was added as part of a reviewer back-out drill.

## What this exercise covers

- Hygiene checks against a brand-new repository (releases, security advisories,
  open pull requests, CI/Actions workflows, runs, and job logs).
- A pull request with a pending review that is started, commented on, and then
  withdrawn (deleted without submitting).

## Expected outcome

No review should remain on the pull request after the pending review is
withdrawn, and no review comment should be published.
